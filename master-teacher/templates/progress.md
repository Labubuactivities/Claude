# Progress Template

A per-session log. One entry per session. The teacher should be able to read this at the start of the next session and pick up exactly where the last one left off, including the diagnostic state and the spaced-retrieval queue.

For a populated example showing what filled-out entries look like, see `progress-example.md`.
